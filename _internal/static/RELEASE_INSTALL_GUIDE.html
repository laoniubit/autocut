运行环境要求

为确保 AI 语义扫描与渲染管线的稳定性，建议满足以下硬件标准：

操作系统 Windows 10/11 (64-bit)
处理器 (CPU) Intel i5/AMD R5 8核及以上
内存 (RAM) 16GB DDR4 (最低 8GB)
显卡 (GPU) NVIDIA GTX 1060+ / RT Core 优先
图形接口 DirectX 12 / WebGPU 支持
网络 仅首次激活需要，后续支持全离线

部署与安装指南

1

物理部署

将下载的压缩包解压至 非系统盘 根目录（如 D:\AutoCut）。请勿包含中文字符或空格的路径，以确保 FFmpeg 引擎调用链路通畅。

2

环境完整性检查

确保 _internal/ 目录下存在 FFmpeg.exe 及 models/ 离线权重文件夹。模型文件缺失将导致 ASR（自动语音识别）功能失效。

3

启动矩阵引擎

直接双击运行 AutoCut_Matrix_AI.exe。若系统弹出防火墙提示，请勾选“允许在专用网络和公用网络上通信”。

授权激活流程

本软件采用硬件锁（HWID）绑定机制，单次激活后支持长期离线使用。

[重要] 网络连接

首次运行软件时需确保计算机能够访问授权服务器。一旦证书下载成功并校准硬件指纹，即可断网运行。

1

获取 HWID

在登录页面的右下角点击“复制硬件指纹”，将 32 位唯一识别码提交给管理员或在管理控制台备案。

2

输入卡密 (CD-KEY)

在授权对话框中输入下发的激活码，点击“在线同步验证”。

授权状态：商业版 (Industrial Production) · 允许离线鉴权

维护与排障 (FAQ)

Q: 启动后黑屏或无法加载控制面板？
A: 请确保使用最新版的 Chrome 或 Edge 浏览器访问地址 http://127.0.0.1:5000。IE 浏览器已被彻底弃用。

Q: 杀毒软件报毒？
A: 由于程序采用 PyInstaller 打包且包含底层硬件劫持侦测逻辑，部分杀毒软件会误报。请将程序目录添加至白名单。

Q: 处理 4K 视频时 GPU 占用极高？
A: 这是正常现象。Matrix AI 引擎会满载调用显卡进行 WebGPU 语义分析，建议在处理期间关闭其他高负载应用。
